### Fretbored
- Beautiful interface with dark theme by default. Other app colour themes from the palette button in the top bar: Light (blue → indigo accents), AMOLED Black (pure black page, near-black boxes, neon cyan → blue accents), Dracula (pink → purple), Solarized dark (yellow → orange), Tokyo Night (night variant; blue → cyan) and the four Catppuccin flavours — Latte (light; mauve → pink), Frappé (green → teal), Macchiato (peach → red) and Mocha (mauve → pink), using the official palettes. Dark keeps the coral → violet accents. Each theme has its own accent colours so active buttons look different per theme. The choice is remembered. (Charcoal and Solarized Light were tried and removed at the owner's request; a saved removed theme falls back to Dark)
- Logo (owner's choice): a fretboard-tile icon whose note dots (dark, with coloured rings, as in the Ring style) spell an F, next to the name "Fretbored" in the Audiowide typeface ("bored" in the theme's second accent colour); the lettering is drawn as SVG shapes, so no font is downloaded
- Works in a web browser with no dependencies
  - Plain HTML, CSS and JavaScript — no build step, no libraries, no network requests
  - Works when `index.html` is opened directly from disk (offline); all sounds, metronome clicks included, are generated in code
  - Hosted on GitHub Pages
  - Installable as an app from the hosted site (PWA): own icon (incl. Android maskable icon), full screen, works offline; an Install button appears in the top bar when the browser offers installation; updates are fetched in the background and used on the next launch
- Works both in desktop browsers and mobile
  - On narrow screens the fretboard scrolls sideways by default; a Layout toggle (phones only) switches it to a vertical fretboard that scrolls down the page
- Link to github repository at the top right corner
- Navigate the application through tabs at the top. Initial version has a tab for Guitar Scales, Guitar Chords, Circle of Fifths, Metronome, plus Arpeggios (after Chords), Trainer (between Arpeggios and Circle of Fifths) and Tuner tabs. Tab order: Scales, Chords, Arpeggios, Trainer, Circle of Fifths, Tuner, Metronome (Tuner and Metronome swapped at the owner's request)
  - On phones, dragging the page left or right goes to the next or previous tab (no wrap-around at the ends). The page follows the finger; letting go past about a third of the screen, or a quick flick, slides it off while the next tab slides in from that side, otherwise it springs back. At the first and last tab it only stretches a little and bounces back. Swipes that start on something that scrolls sideways (the sideways fretboard, the tab bar), a slider or a dialog are left alone
- Wherever a fretboard appears (Scales, Chords, Arpeggios, Trainer) it is the first section on the tab; likewise the circle of fifths wheel is the first section of its tab
- On the Scales, Chords, Arpeggios and Circle of Fifths tabs, a slim bar is pinned to the bottom of the screen and always stays in the same place while scrolling. It shows the current scale, chord, arpeggio or key (name and notes) with its play button; a ↑/↓ button jumps to the controls and appears only while the title is out of view
- All settings (tab, theme, fretboard options, custom tunings, last selections, metronome settings) are remembered between visits in the browser's local storage (written immediately when the app is hidden or closed, so a change made just before leaving — e.g. the arpeggio speed — isn't lost)
- Settings button (⚙, top bar, next to the palette) opens a Settings dialog, which holds the guitar settings, the arpeggio direction and speed, the trainer's setup, the metronome's click sound and backup. Backup: **Export settings & progress** downloads `fretbored-backup-<date>.json` with everything stored in the browser (settings, theme, custom tunings, Trainer history and daily streak); **Import from a backup file…** asks for confirmation, replaces everything on this device and reloads. Use it to move progress between devices or keep a copy
- For any tabs which show notes on the fretboard, the fretboard display is common among those tabs and allows for adjusting to common tunings, Changing the number of strings (6, 7, 8, and even 4 or 5 for bass), changing the number of frets (21, 22, or 24); the note dot colours come from the app colour theme
  - The guitar settings are in the Settings dialog's "Guitar" section (renamed from "Fretboard settings" at the owner's request), not on the tabs. They apply to every tab with a fretboard (Scales, Chords, Arpeggios, Trainer). Decision (owner, moving them out of the tabs): the tabs keep only what is played or shown on them
  - Tone: Clean (default) or Overdriven (a Distortion option was tried and removed at the owner's request — too messy) — the sound of every note the app plays (Scales, Chords, Arpeggios, Trainer, Circle of Fifths). Notes share one amp chain so strummed chords break up together; levels are roughly matched to Clean. The Tuner's reference tones always stay clean
  - Palm mute switch: notes are damped like a palm resting at the bridge — they die within a few tenths of a second, darker, with a softer attack (level matched to open notes). Pairs well with Overdriven for chugs
  - Reverb: Off / Room / Hall, and Delay: Off / Slapback (0.11 s) / Echo (0.36 s, darkening repeats that also feed the reverb). The reverb is generated in code (no sound files). Like the tone, these apply to every note except the Tuner's reference tones
  - Preset tunings per string count, including drop tunings for 7-string (Drop A, Drop G♯, Drop G) and 8-string (Drop E, Drop E♭, Drop D) guitars
  - Fully custom tuning editor: set each string's note and octave, name it, save it; custom tunings can be edited or deleted later
  - Dot labels toggle between note names and interval degrees (1, ♭3, 5 …)
  - Note names are spelled correctly for the key (sharps vs flats chosen automatically, e.g. B♭ in F major, F♯ in G major)
  - Left-handed mode mirrors the fretboard
  - Layout (phones): Sideways or Vertical — vertical shows the nut at the top and the low string on the left, like a chord chart
  - On Chords and Arpeggios the vertical fretboard shows only the frets around the current shape (from the nut when the shape is near it, at least five frets, one spare fret below for editing); a "Show the whole neck" button below it brings back the full neck (remembered)
  - Fretboard wood: Ebony (default), Rosewood or Maple
  - App style (palette button, "Style" column beside the colour themes; remembered): changes the look of note dots, buttons and tabs while keeping the theme's colours. Listed in this order: Ring (default — the owner's pick: dark/black dots with a coloured ring and label; active buttons and tabs outlined with Classic's accent gradient); Classic (the original look: filled dots, gradient buttons, pill tabs); Target (solid dot inside a ring of its colour; Classic's gradient buttons with a double ring). Glass, Flat, Pixel, Sticker, Pearl and Neon were tried and removed at the owner's request; a saved removed style falls back to Ring
  - Note dot colours follow the app colour theme (the separate dot-colour picker was removed at the owner's request). Root / other notes: Dark coral / violet (the circle-of-fifths colours), Light rose / blue, AMOLED cyan / electric blue, Dracula pink / cyan, Solarized orange / blue, Tokyo Night orange / blue, Catppuccin Latte mauve / teal, Frappé green / mauve, Macchiato red / yellow, Mocha mauve / teal
##### Guitar Scales Tab
- User may select any key desired, and they display in the fretboard with root note highlighted
- The user may select scales from 3 categories: Common, Rare, Exotic
- User may click on a fret to add or remove a note, or change the root note. The program will automatically figure out if this changes to some other known scale and adjust the selection accordingly.
  - Click / tap a fret to add or remove that note everywhere on the neck
  - Right-click (desktop) or long-press (touch) a note to make it the root
  - A "Tap to: Add / remove · Set root" switch under the fretboard lets a plain tap set the root, as a gesture-free alternative
  - If the notes don't form a known scale, the scale is shown as "Custom" with the closest matches (e.g. "Dorian +B −B♭") and any scale the same notes form from another root; tapping a suggestion selects it
  - Scales that share the same notes as other scales/modes are listed (e.g. C Major = D Dorian = A Natural Minor …)
- The user may press play (in the pinned bar), which will play a brief ascension up the scale until the next octave; there is no Stop, and pressing Play again restarts it from the root
  - Notes light up on the fretboard as they play
##### Guitar chords tab
- Similar to guitar scales tab, the user may select any root note
- The user may then select the type of chord, major minor, 7, 5, dim, dim7, aug, sus2, sus4, maj7, m7, 7sus4
- There is an "Advanced" button which will reveal many more advanced and uncommon chords
  - 6, m6, 6/9, add9, m(add9), add11, 7sus2, m7♭5, m(maj7), 7♭5, 7♯5, maj7♯5, maj7♭5, 9, maj9, m9, 7♭9, 7♯9, 9sus4, 7♯11, 11, m11, 13, maj13, m13
- There is a position selection as well, example 1, 2, 3, 4, 5, which designates roughly how far up on the fretboard the chord lands.
  - Playable voicings are generated for the current tuning (root in the bass, max 4 fingers or a barre, 4-fret span)
  - A chord diagram shows the selected shape, with the same chord as tablature beside it (one column, highest string on top, x for muted strings, roots highlighted) and the usual shorthand underneath (low string first, e.g. x32010); the "Strum" button in the pinned bar plays it (no Stop; pressing it again strums again)
  - "All chord tones" toggle shows every chord tone on the neck behind the selected shape
- User may also manually add or remove notes by clicking on them, and the application will automatically figure out if there is some chord match and change the selection
  - Tapping a fret moves that string's note there; tapping a played note again mutes the string
  - Inversions are named as slash chords (e.g. C/E), and alternative names are shown (e.g. C6 = Am7/C)
##### Arpeggios tab
- Similar to the chords tab: pick any root and an arpeggio type (the same basic and Advanced types as chords)
- Style: **Positions** or **Sweep** (the owner checked the shapes against the commonly taught ones)
  - Positions: the five CAGED shapes per octave, each a 5-fret window anchored on a root (E and G shapes on the 6th string, A and C on the 5th, D on the 4th) holding every chord tone once — e.g. E major: E shape 0–4, D 1–5, C 4–8, A 7–11, G 9–12. Buttons read "A 7" (A shape from fret 7). Shape names appear in standard-like tunings; other tunings get numbered positions
  - Sweep: sweep-picking shapes — 6-, 5- and 4-string sweeps from a root to a root on the top string, and 3-string sweeps on the top three strings from each chord tone to its octave; at most two notes per string (hammer-ons/pull-offs), within a 6-fret span. E.g. E major 5-string: A 7·11, D 9, G 9, B 9, e 7·12. Buttons read "5-str 7"
- The shape is shown as dots on the shared fretboard (roots highlighted; "All arpeggio tones" shows the rest of the neck faintly) and as tablature in playing order, so it's easy to see how to play it
- Direction: Up, Down (highest note first) or Up & down, and the six speeds, are set in Settings (not on the tab); Play button (in the pinned bar) with six speeds — Slow, Medium, Fast, Faster, Shred (≈13 notes/s, 16ths at 200 BPM) and Max shred (20 notes/s, 16ths at 300 BPM); two rows of three on phones — the current note lights up in the tab and on the fretboard; the last note rings as long as the others (it used to ring out for over a second, which sounded unnatural at fast speeds)
- Edit the shape like on the Scales and Chords tabs: tap a fretboard note to add it (it plays) or tap a note in the shape to remove it. The shape becomes "Custom" and the arpeggio is identified from its notes (lowest note preferred as the root); other names for the same notes are offered under "Also" (tap one to switch), and long-press / right-click a note to make it the root. Chord tones missing from the shape are greyed; notes that match nothing show "? Unknown arpeggio". Tab and playback follow the custom notes (low to high). Choosing a root, type, style or position goes back to the generated shapes; a custom shape is remembered, and dropped if the tuning changes
- Play (in the pinned bar) starts the arpeggio from its first note; there is no Stop. Pressing Play again while it plays cuts the notes still queued and starts over. Changing the root, type, shape or direction while it plays doesn't stop it; leaving the tab or changing the tuning does
- The pinned "now viewing" bar shows the arpeggio while scrolling

##### Circle of Fifths
- A beautiful circle of fifths is displayed
  - Rings for major keys, relative minors and diminished chords, plus key signatures
- The user may change the key or the mode, and the display will update with the new information
  - The seven diatonic chords are highlighted on the circle with Roman numerals relative to the tonic
  - Shows the scale's notes, diatonic triads and seventh chords (tap to hear), key signature, relative keys and the mode's character
  - Diatonic segments use the app colour theme's dot colours (tonic in the root colour); the Ring style draws them as dark tiles with coloured rings, like the fretboard dots
  - Play scale is available from the pinned bar at the bottom of the screen
  - Clicking a segment of the circle selects that key; "Show on fretboard" opens the scale in the Scales tab
    - The clicked segment becomes the tonic: the outer ring keeps a major-type mode (Ionian, Lydian, Mixolydian, else Ionian), the middle ring a minor-type mode (Dorian, Phrygian, Aeolian, else Aeolian), the inner ring selects Locrian
##### Trainer
- A fretboard trainer game using the shared fretboard (same tunings, strings, frets and display settings as the other tabs)
- Two games:
  - Name the note: a random note is highlighted on the fretboard (with its string and fret shown) and the user picks its name from 12 buttons below the fretboard (sharp/flat names shown together)
  - Find the note: the app names a note and the user taps every place it occurs in the practice area; a miss shows the tapped note in red; three misses or "Show answer" reveals them all; a round counts as correct only with no misses
- The practice area can be limited to a section of the neck — presets (Open–12 — the default, Open–4, 5–9, 7–12, 12–17, All frets) or any custom from/to fret range — and to chosen strings ("Quiz strings")
- Game, frets, quiz strings and options are set in Settings (the Trainer section), so the tab shows the board, score and progress
- Options: Natural notes only (hides the sharp/flat buttons), Dim outside range (shades the frets and strings not being quizzed), Focus on weak spots (asks more often the notes and positions answered wrong or slowly before), Play sound (plays the note with each question, with a Replay button)
- Tracks points, questions asked, correct answers, accuracy, average answer time and the current/best streak; Reset score button
- Answer speed: each question is timed from when it appears. A right answer scores 50 points plus a speed bonus of up to 50 (full at 1.5 s or quicker, none from 6 s); wrong answers score 0. The time and points show after each right answer ("✓ Correct — C · 1.4 s · +89"). In Find the note the time is per note found. Times are kept for right answers only, capped at 10 s, and not taken when the page was hidden or the tab left mid-question
- 60-second challenge: count correct answers in a minute (with the average answer time); the best score per game is saved
- Progress saved on the device: questions and accuracy for each of the last 7 days (bar chart), accuracy and average answer time by note and by string with weak ones (under 70% right) flagged "⚠ weak" and slow ones (40% slower than your average, and over 1.5 s) "🐢 slow"; the 7-day chart's tooltips include each day's average time; Reset progress button
- Daily streak: answering at least 50 notes in a day (right or wrong) keeps it going. Shown as "🔥 N" in the score row ("Day streak", next to "In a row" = correct answers in a row) and in a Daily streak section with today's progress bar towards 50 and the best streak; a toast celebrates the 50th note; days that reached 50 are highlighted in the 7-day chart. The streak stays alive until the end of the following day. It is stored separately from the 90-day history (so it can run longer) and was rebuilt from that history for progress saved before streaks existed
- Immediate feedback: correct answers flash green and move on; a wrong answer marks the pick red, shows the right note on the fretboard and button, then moves on
- Keyboard: letter keys A–G answer naturals, Shift+letter answers the sharp

##### Metronome
- A full featured metronome, allowing the user to adjust tempo, tap tempo, accents (meter, beats, division), and a trainer mode which allows a user configurable increase in tempo from a start to end tempo at steps, and also a gradually accelerating mode
  - Tempo 20–300 BPM via slider, ±1/±5 buttons (hold to repeat), number entry, tap tempo, or keyboard (Space, ↑/↓, T)
  - Meter: 1–16 beats over 2, 4, 8 or 16; beat grouping for compound/odd meters (e.g. 7/8 as 2+2+3)
  - Per-beat accents: tap a beat to cycle accent / normal / soft / mute
  - Subdivisions: eighths, triplets, sixteenths, quintuplets, sextuplets, swing, dotted, and mixed 8th/16th figures
  - Sounds: Classic, Digital and Beep (the click sound, volumes and visual sync are in Settings → Metronome sound), generated in code and identical to the NAMsayin plugin's metronome (Classic recreates the originally supplied click exactly; Digital is NAMsayin's square-wave click, replacing the supplied sample); separate volume for subdivisions
  - Visual sync: for devices whose audio comes out late or early (e.g. Bluetooth speakers), a slider shifts the beat lights and sweep from 100 ms earlier to 300 ms later, in 5 ms steps (− / + buttons for fine steps, Reset). Only the visuals move; the audio timing is untouched. Remembered per device
  - Trainer: Step mode (+N BPM every M bars from start to end tempo) and Gradual mode (smooth ramp over N bars); works for slowing down too
  - Gap trainer: play N bars, then mute M bars to test internal time
  - Visual pulse and sweeping indicator synced to what you hear
  - Keeps the screen awake while running on supporting mobile browsers
- The timing must be perfectly accurate
  - Every click is scheduled on the Web Audio clock (sample-accurate), ahead of time, so browser timer jitter never affects the audio
##### Tuner
- A full featured tuner using the device microphone, with traditional and strobe tuning modes
  - Traditional: needle gauge (±50 cents) with note name, octave, cents offset, frequency and "tune up / tune down" guidance; green when within ±2 cents
  - Strobe: three rows of moving bands (fundamental and two octaves, like a Peterson strobe) whose speed shows how far out of tune you are; the bands stand still when in tune
  - Instrument mode tunes to the strings of the current tuning (shared with the fretboard; the tuner has no strings or tuning picker of its own, those are in Settings → Guitar), auto-detecting the string or locked to one string; Chromatic mode tunes to the nearest note
  - Adjustable reference pitch (A4 = 415–466 Hz, default 440) and sensitivity (noise gate)
  - Reference tone button plays the target note for tuning by ear
  - Accurate to a fraction of a cent from a 5-string bass's low B (31 Hz) up to the 24th fret (McLeod pitch detection with an FFT-based autocorrelation)
  - The microphone is only opened while the tuner is running and is released when leaving the tab; audio is analysed on the device and never leaves it
